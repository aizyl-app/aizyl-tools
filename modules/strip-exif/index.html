Co kryje się w metadanych zdjęcia

Lokalizacja GPS

Zdjęcia z telefonu zawierają dokładne współrzędne miejsca gdzie zostały zrobione. Każdy może sprawdzić gdzie mieszkasz.

Data i godzina

Dokładna data i czas wykonania zdjęcia. Może zdradzać Twój rozkład dnia lub kiedy byłeś pod danym adresem.

Model urządzenia

Producent i model aparatu lub telefonu, wersja oprogramowania. Informacje które możesz woleć zachować dla siebie.

Jak to działa

Canvas API rysuje obraz od nowa i eksportuje go bez oryginalnych metadanych. Prosto i skutecznie.

Usuwanie EXIF jest w pełni lokalne. Zdjęcia są przetwarzane przez Canvas API bezpośrednio w przeglądarce. Żaden plik nie opuszcza Twojego komputera.
